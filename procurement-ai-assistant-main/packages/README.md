# Ready-to-upload Skill ZIPs

Use these files when your AI product supports Agent Skills upload.

- Each `<skill-name>.zip` contains exactly one skill folder at the ZIP root.
- That folder contains `SKILL.md` with required YAML metadata.
- `procurement-ai-assistant-all-skill-zips.zip` contains all individual installer ZIPs for one download. Extract it before installing skills.
- `procurement-ai-assistant-agent-skills-source.zip` contains the uncompressed Agent Skills folders for advanced users.

See the platform-specific guides in `guides/`.
