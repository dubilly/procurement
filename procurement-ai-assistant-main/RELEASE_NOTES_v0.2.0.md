# Procurement AI Assistant v0.2.0

## What changed

This release adds ready-to-upload Agent Skills packages for the complete Procurement AI Build Lab library.

### Included native skills

- procurement-skill
- procurement-intake-skill
- market-research-skill
- rfp-drafting-skill
- pricing-model-review-skill
- sla-review-skill
- contract-risk-review-skill
- negotiation-prep-skill
- supplier-qbr-skill
- spend-analysis-skill

Each installer ZIP contains one skill folder with `SKILL.md`, YAML frontmatter, and an MIT licence file.

### New guides

- ChatGPT Skills installation
- Claude custom Skills installation
- Microsoft 365 Copilot / Copilot Studio implementation
- Installation overview

### Packaging

The repository keeps the original human-readable `.md` workflow files in `skills/` and adds cross-platform Agent Skills versions under `agent-skills/`. Ready-made individual ZIPs are in `packages/`.

### Important

The Procurement AI Assistant supports research, drafting, analysis, risk identification, and preparation. Human procurement, legal, finance, privacy, security, technical, and business review remains required where relevant.
