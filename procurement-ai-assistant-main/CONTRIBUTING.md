# Contributing

Contributions are welcome.

## Ways to contribute

- Report an error or unclear instruction
- Suggest a new procurement workflow
- Improve a guardrail or review check
- Add a worked example
- Test a skill and share structured feedback

## Contribution principles

- Keep skills model-agnostic where practical
- Preserve human accountability
- Do not include confidential or supplier-proprietary content
- Separate procurement support from final legal advice
- Protect public procurement fairness and defensibility
- Clearly state assumptions and limitations

## Suggested change format

1. Problem or use case
2. Proposed change
3. Procurement benefit
4. Risks or guardrails
5. Example input and expected output
