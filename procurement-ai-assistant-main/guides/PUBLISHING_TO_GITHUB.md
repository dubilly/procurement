# Publishing This Project to GitHub — Beginner Guide

## Recommended repository settings

- Repository name: `procurement-ai-assistant`
- Description: `A reusable AI skill library for procurement workflows, sourcing, contracting and supplier management.`
- Visibility: **Public**
- License: **MIT**

## Step 1: Create a GitHub account

Create or sign in to your GitHub account.

## Step 2: Download and unzip the project

Download the project ZIP from ChatGPT and extract it on your computer.

You should see `README.md`, `LICENSE`, and folders including `skills`, `guides`, `assistant`, `examples`, and `templates`.

Do not upload only the ZIP file as the repository content. Upload the extracted files and folders so visitors can read them online.

## Step 3: Create an empty repository

1. On GitHub, select the **+** menu in the upper-right corner.
2. Select **New repository**.
3. Enter `procurement-ai-assistant`.
4. Add the description above.
5. Select **Public**.
6. Do not add another README, `.gitignore`, or licence because the project package already contains them.
7. Select **Create repository**.

## Step 4: Upload the project

1. On the empty repository page, choose the option to upload existing files.
2. Open the extracted project folder on your computer.
3. Drag all files and folders inside it into the GitHub upload page.
4. Confirm that the folders are visible in the upload list.
5. In the commit message, enter: `Publish Procurement AI Assistant v0.1.0`.
6. Commit the files to the `main` branch.

## Step 5: Check the repository

Confirm that the repository homepage displays the README and that these folders open correctly:

- `skills`
- `guides`
- `assistant`
- `examples`
- `templates`

Open two or three files to confirm that the Markdown renders correctly.

## Step 6: Add repository topics

In the repository's About section, add topics such as:

- procurement
- procurement-ai
- generative-ai
- strategic-sourcing
- vendor-management
- contract-management
- workflow-automation
- skill-md

## Step 7: Create the first release

A release gives users a clear version to download.

1. Open **Releases** on the repository page.
2. Select **Draft a new release**.
3. Create the tag `v0.1.0`.
4. Release title: `Procurement AI Assistant v0.1.0`.
5. Add release notes describing the parent skill, nine child skills, user guides, and examples.
6. Optionally attach the project ZIP.
7. Publish the release.

GitHub also creates source-code ZIP and TAR downloads for releases.

## Step 8: Share it

Share the repository URL in your LinkedIn series and direct users to:

- README for the overview
- Getting Started guide for implementation
- Releases for the easiest download

## Step 9: Update it later

For small changes:

1. Open the file on GitHub.
2. Select the edit icon.
3. Make the change.
4. Preview it.
5. Commit the update with a clear message.

For larger updates, GitHub Desktop may be easier, but it is not required for the first release.
