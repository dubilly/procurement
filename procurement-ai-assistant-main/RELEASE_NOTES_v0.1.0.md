# Procurement AI Assistant v0.1.0

Initial public release of the Procurement AI Assistant skill library.

## Included

- One parent procurement skill for context, routing, guardrails, and human decision boundaries
- Nine child workflow skills:
  - Procurement intake
  - Market research
  - RFx drafting
  - Pricing-model review
  - SLA/KPI review
  - Contract-risk review
  - Negotiation preparation
  - Supplier QBR preparation
  - Spend analysis
- Master assistant instructions
- Skill-routing manifest
- Beginner implementation guide
- GitHub publishing guide
- Governance and safety guidance
- Prompt, input-pack, and SaaS renewal examples

## Current scope

This release is a model-agnostic instruction and workflow library. It is not yet a self-executing plugin or autonomous agent.

## Important

All outputs require human validation. The project does not replace procurement judgment, legal advice, specialist review, evaluator scoring, supplier selection, award approval, or contract signature.
