# Example: SaaS Renewal Workflow

## Scenario
A SaaS platform expires in four months. The supplier proposes an 8% increase. Licence usage and alternatives are unclear.

## Recommended skill sequence

1. `procurement-intake-skill.md`
   - Clarify business need, timeline, stakeholders, contract status, and missing information.

2. `spend-analysis-skill.md`
   - Review historical spend, licences, active usage, modules, overlaps, and renewal exposure.

3. `market-research-skill.md`
   - Identify credible alternatives and switching considerations.

4. `pricing-model-review-skill.md`
   - Review the increase, cost drivers, volume bands, escalation, optional charges, and TCO.

5. `contract-risk-review-skill.md`
   - Review renewal, termination, data return, SLA, liability, and transition terms.

6. `negotiation-prep-skill.md`
   - Build asks, leverage, concessions, pushback responses, fallback positions, and approval items.

## Example request

```text
Use the Procurement AI Assistant for this SaaS renewal. Start with intake, then route to spend, market, pricing, contract, and negotiation skills as needed. At each stage, state assumptions, missing information, risks, and human decisions.
```
